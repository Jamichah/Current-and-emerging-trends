# Current-and-emerging-trends
Project Overview

I used reinforcement learning and neural networks to make a pirate intelligent agent for this project. It was the goal to teach an AI-controlled pirate how to find the wealth in a maze while also getting better at making choices over time. I learned about deep Q-learning through the project. This method uses neural networks and reinforcement learning to help a robot learn from its mistakes. Because of this assignment, I now understand that artificial intelligence can figure out how to solve problems without following a set of predetermined steps.

What Code Was I Given, and What Code Did I Create Myself?

I was given starting code for this project that had the maze environment, supporting classes, and functions I needed to talk to the pirate agent. The given code set up the basics of the game, like how the pirate could get through the maze and how the environment would react to its actions.

It was up to me to finish putting together the deep Q-learning training so the pirate could figure out how to get through the maze. In order to help the agent make better decisions, I worked with the neural network, experience replay, and training parameters. I also put the trained model to the test to see if the pirate could get to the treasure from where it started. I learned more about how reinforcement learning algorithms work and how different training choices can affect how well an AI model does by working on this project.

What Do Computer Scientists Do, and Why Does It Matter?

Computer scientists work in many fields to create, study, and improve technology that helps people solve problems. As part of their job, they create software, make algorithms, manage data, make cybersecurity better, and build systems that use artificial intelligence. Computer science is important because technology is used in almost every part of our lives, from getting around and getting medical care to school and running a business.

I learned that computer scientists do more than just write code in this class. They also look at different options, see how well they work, and think about how technology will change the lives of those who use it. My Pirate Intelligent Agent project showed how algorithms and machine learning can be used to solve problems that need people to be able to make choices and change their minds.

How Do I Approach a Problem as a Computer Scientist?

As a computer scientist, I start solving problems by figuring out what the goal is and what needs to be done to reach it. Then I break the problem down into smaller, easier-to-handle steps and figure out which computer languages, tools, or algorithms will work best. When I have an answer, I test it, look at the results, and if needed, make changes to make it better.

This project made that approach stronger because it took time and trial and error to train the pirate agent. I had to figure out how the agent moved through the maze, how rewards affected its choices, and how the neural network remembered what it had done before. I also learned that just because a solution gets a program to run well, it means it works. It is just as important to test and evaluate the results as it is to write the code.

What Are My Ethical Responsibilities to the End User and the Organization?

As a computer scientist, it's my job to make sure that the technology I work on is trustworthy, safe, fair, and useful for people. This means keeping private data safe, reducing bias, testing software carefully, and being honest about what a system can't do. Developers are needed by businesses to make sure that their products work properly, keep users safe, and keep trust.

This class taught me that artificial intelligence comes with more moral duties because AI systems can decide what to do based on the data and rewards they are given. If you train an AI system with wrong data or rewards that aren't well thought out, it might do things that you didn't want it to do. The Pirate Intelligent Agent I made was a controlled learning environment, but the same ideas can be used in real-life AI situations. From now on, I want to make sure that the systems I build are thoroughly tested, planned responsibly, and made with the needs of the end user in mind.
